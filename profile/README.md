# ACKaraca

A studio working where architecture and software meet. We turn complex ideas into legible spaces, products, and tools.

**Website:** [ackaraca.me](https://ackaraca.me) · **Contact:** [info@ackaraca.me](mailto:info@ackaraca.me)

## What we do

- **Architecture tools:** Open-core CAD/BIM editors for architectural design and BIM workflows, plus AI-assisted design review simulations.
- **Products:** Mobile and web applications, including local-first, privacy-focused activity tracking and discovery apps.
- **Games:** Simulation, strategy, and co-op games built with Godot, Unreal Engine 5, and .NET.
- **Experimental making:** Creative technology experiments that bridge physical presentation boards and digital layers.

## How we work

Architectural thinking and software development are different scales of the same decision-making discipline: reading context, constraints, and human movement, then testing those decisions through states, feedback, and repeated flows. We build every project so that these two worlds reinforce each other.
